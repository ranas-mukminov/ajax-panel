# AJAX Panel для Grafana (форк от run-as-daemon.ru)

Production-ready плагин панели Grafana для загрузки внешнего контента через AJAX (GET/POST) или iframe прямо в дашборды.

[Русский] | [English](README.md)

## Обзор

Плагин AJAX Panel предоставляет гибкий способ загрузки и отображения внешнего контента непосредственно в дашбордах Grafana. Нужно ли вам интегрировать сторонние API, встроить страницы статуса или отобразить пользовательские HTML/JSON-ответы — этот плагин позволяет делать это, не покидая среды мониторинга.

Типичные сценарии использования:

- Встраивание внешних страниц статуса или дашбордов мониторинга
- Вызов REST API и отображение ответов в различных форматах
- Отображение JSON, HTML или текста из внутренних сервисов
- Создание простых панелей управления или кастомных виджетов внутри дашбордов Grafana
- Загрузка динамических изображений или трансляций с веб-камер
- Интеграция эндпоинтов, защищённых собственной аутентификацией

## Основные возможности

- **Несколько HTTP-методов**: поддержка GET, POST и встраивания через iframe
- **Интеграция с переменными Grafana**: использование template-переменных (`$__from`, `$__to`, `$__interval` и пользовательских) в URL и параметрах
- **Гибкие режимы отображения**: рендеринг контента как HTML, plain text, JSON-дерево, preformatted-текст, изображения или Angular-шаблоны
- **Настраиваемые заголовки**: возможность установки пользовательских HTTP-заголовков и аутентификации
- **Скриптовые параметры**: JavaScript-объект для параметров с доступом к объекту `ctrl` и контексту дашборда
- **Индикаторы загрузки**: встроенный спиннер и улучшенная обработка ошибок
- **Интеграция с источниками данных**: возможность использовать конфигурации источников данных Grafana для аутентификации
- **Реализация на TypeScript**: современная, типобезопасная кодовая база

## Как это работает

AJAX Panel работает следующим образом:

1. Панель настраивается с целевым URL, HTTP-методом и опциональными параметрами
2. При обновлении дашборда или изменении временного диапазона панель отправляет запрос
3. Ответ обрабатывается в соответствии с выбранным режимом отображения
4. Template-переменные и контекст дашборда (временной диапазон, интервал) автоматически доступны для использования в запросах
5. Отрендеренный контент динамически обновляется внутри панели

## Установка

### Вариант 1: Установка из каталога плагинов

1. Скачайте или клонируйте этот репозиторий
2. Скопируйте папку плагина в каталог плагинов Grafana:
   ```bash
   cp -r ajax-panel /var/lib/grafana/plugins/
   ```
3. Если плагин не подписан, включите его в `grafana.ini`:
   ```ini
   [plugins]
   allow_loading_unsigned_plugins = ryantxu-ajax-panel
   ```
4. Перезапустите Grafana:
   ```bash
   systemctl restart grafana-server
   ```

> **ПРИМЕЧАНИЕ**: Скорректируйте путь к каталогу плагинов (например, `/var/lib/grafana/plugins`) и конфигурацию в соответствии с вашей установкой Grafana.

### Вариант 2: Сборка из исходников

1. Установите зависимости:
   ```bash
   yarn install
   ```
2. Соберите плагин:
   ```bash
   yarn build
   ```
3. Скопируйте каталог `dist` в папку плагинов Grafana:
   ```bash
   cp -r dist /var/lib/grafana/plugins/ryantxu-ajax-panel
   ```
4. Включите неподписанные плагины (если необходимо) и перезапустите Grafana, как описано выше

## Настройка

### Базовая настройка

1. Откройте дашборд в Grafana
2. Добавьте новую панель
3. Выберите **AJAX** в качестве типа визуализации
4. Настройте опции панели

### Опции панели

#### Метод (Method)

Выберите метод запроса:

- **GET**: стандартный HTTP GET-запрос (по умолчанию)
- **POST**: HTTP POST-запрос с параметрами в теле запроса
- **iframe**: встраивание контента через iframe

#### URL

Целевой эндпоинт для запроса. Поддерживает template-переменные Grafana:

- `$__from` — начало временного диапазона дашборда (Unix timestamp в миллисекундах)
- `$__to` — конец временного диапазона
- `$__interval` — текущий авто-интервал
- `$__interval_ms` — текущий авто-интервал в миллисекундах
- Любые пользовательские переменные дашборда

Пример:
```
https://api.example.com/status?from=$__from&to=$__to
```

#### Параметры (Parameters)

JavaScript-объект, определяющий query-параметры (для GET) или тело запроса (для POST). Доступны:

- `ctrl` — объект контроллера панели
- `ctrl.range.from` / `ctrl.range.to` — объекты временного диапазона
- `ctrl.height` — высота панели
- Template-переменные через `ctrl.template('$variable')`

Пример:
```javascript
{
  from: ctrl.range.from.format('x'),
  to: ctrl.range.to.format('x'),
  interval: ctrl.template('$__interval'),
  custom_var: ctrl.template('$my_variable')
}
```

#### Заголовки (Headers)

Пользовательские HTTP-заголовки в виде JavaScript-объекта. Полезно для аутентификации:

```javascript
{
  'Authorization': 'Bearer YOUR_TOKEN',
  'Accept': 'application/json'
}
```

#### Режим отображения (Display Mode)

Выберите, как рендерить ответ:

- **HTML**: рендеринг как HTML (небезопасный контент будет санитизирован)
- **Text**: отображение как экранированный plain text
- **JSON**: форматированный JSON с раскрываемым деревом
- **Pre**: отображение в блоке preformatted-текста
- **Image**: отображение как изображение (для бинарных image-ответов)
- **Template**: использование Angular-шаблона для форматирования ответа

### Примеры

#### Пример 1: Простой GET-запрос

**URL**: `https://httpbin.org/anything?interval=$__interval`  
**Метод**: GET  
**Параметры**:
```javascript
{
  from: ctrl.range.from.format('x'),
  to: ctrl.range.to.format('x')
}
```
**Режим отображения**: JSON

#### Пример 2: Встраивание страницы статуса через iframe

**URL**: `https://status.example.com`  
**Метод**: iframe  
**Параметры**: `{}`

## Безопасность

При использовании AJAX Panel учитывайте следующие соображения безопасности:

- **Недоверенный контент**: будьте осторожны при загрузке внешнего HTML или JavaScript. Вредоносный контент может выполняться в контексте вашего экземпляра Grafana (XSS-атаки)
- **CORS-ограничения**: cross-origin запросы могут блокироваться браузерами. Убедитесь, что целевые эндпоинты имеют соответствующие CORS-заголовки, или проксируйте запросы через источники данных Grafana
- **Аутентификация**: избегайте встраивания API-ключей или секретов напрямую в конфигурацию панели. По возможности используйте источники данных Grafana с аутентификацией
- **HTTPS**: используйте HTTPS-эндпоинты для предотвращения предупреждений о смешанном контенте и обеспечения безопасности данных
- **Внутренние эндпоинты**: предпочтительно загружать контент из доверенных внутренних сервисов, а не произвольных внешних URL
- **Раскрытие учётных данных**: конфигурация панели видна пользователям с правами редактирования дашборда

## Разработка

### Требования

- Node.js (рекомендуется v14 или новее)
- Менеджер пакетов Yarn

### Процесс разработки

1. Установите зависимости:
   ```bash
   yarn install
   ```

2. Запустите режим разработки с live reload:
   ```bash
   yarn dev
   ```
   или
   ```bash
   yarn watch
   ```

3. Сборка для production:
   ```bash
   yarn build
   ```

4. Запуск тестов:
   ```bash
   yarn test
   ```

Исходный код плагина находится в каталоге `src/`, результаты сборки — в `dist/`.
